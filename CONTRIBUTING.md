# Contributing to record-history

Thank you for improving this project.

## Development setup

1. Clone [unified-field-dev/record-history](https://github.com/unified-field-dev/record-history)
2. Install Rust stable
3. From the repository root:

```bash
cargo fmt --all -- --check
cargo check --workspace --features ssr
```

## Code of conduct

Participation is governed by [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md). Security reports: [`SECURITY.md`](SECURITY.md).

## Pull requests

- Prefer small, focused PRs.
- Update [`README.md`](README.md) when public API or UI flows change.
